# 架构、索引与阅读位置

## 当前结构

浏览器处理阅读 UI，Python 提供本地导入、OCR、任务、服务设置与存储。Swift 组件负责 macOS Vision OCR、NSPanel / WKWebView 掌上窗口与钥匙串。原型没有前端打包步骤；阅读和存储保留本机，AI 仅在用户发送问题或连接测试时调用配置的模型服务。

![导入与索引流程](../indexing-flow.drawio.svg)

## 输入如何变成阅读资料

| 来源            | 索引来源                                     | 阅读定位                     |
| --------------- | -------------------------------------------- | ---------------------------- |
| EPUB 3 / EPUB 2 | 原生 nav / NCX，缺少时沿用 OPF spine         | 正文文件 + 段落锚点          |
| PDF             | 原有 outline 优先，否则 OCR 读取扫描目录     | 实际文件页序；印刷页码另映射 |
| TXT             | 共用章 / 回 / 卷、Chapter / Part / Book 规则 | 章节 + 归一化原文字符位置    |
| 其他文档        | 本地格式适配器读取或转换                     | 对应文件、标题与锚点         |
| CBZ             | 图像文件自然数字顺序                         | 对应图像页                   |

前端得到统一目录节点，包含标题、文件 / 页序、片段锚点和子节点。目录 UI 不为特定书籍定制规则。

扫描目录流程查看前 48 页，识别目录标题 / 引导线，对候选页细读，合并同行标题与页码并区分双栏，再用正文页眉 / 页脚的重复一致偏移校准文件页序。无法确认时保留未确定状态，允许手动校正。

## 为什么原 PDF 上能选择文字

页面仍由 PDF.js 显示。原生文字层可用时直接使用；扫描页在后台按页 OCR，再把文字坐标放在透明选择层中。平时只显示原版面，选中后才出现工具栏。

Vision 负责中文 / 快速布局识别，Tesseract 负责英文精细识别。`mineru_api.py` 按用户指定的原页分批调用云 API v4，解析 `layout.json`，将区块转换为归一化坐标。原页显示、透明文字层和对象层分开；新增结果立即用于完整公式 / 表格 / 图片取用。

OCR 文字与原页面可能不完全一致，尤其数学公式。透明文字层解决可选取问题，不等于已经解决识别准确率与字符级精确对齐。

## 分页、动画与锚点

EPUB 和 TXT 使用真实 DOM 多栏，而非不可选择的整页截图。每栏对应一屏，字体、宽度或窗口变化后重新排页。

动画层是临时的旧页副本，做少量水平位移与淡出；实际正文只做透明度过渡，其选择几何位置保持固定。重复翻页先取消并清理旧动画。减少动态效果时直接切页，过长全文不克隆整本 DOM。

阅读位置使用章节、段落特征和段内字符位置；TXT 另存归一化原文的字符偏移。通过 Range 几何计算可见文字，避免设置弹窗遮挡造成段内位置丢失。程序恢复时保留原锚点，实际翻页 / 滚动后才更新位置。

## 小窗与主窗口

掌上窗口加载同一个阅读页面的 `mode=palm` 分支。默认置顶，可取消；字号按窗口可用面积的平方根缩放，并限制在可用区间内。

两个窗口通过本地服务共享状态，约 1.8 秒检查更新；程序恢复位置时抑制重复写回。窗口打开 / 复用通过本地状态与指令文件协调，启动新窗口前清理过期指令。

## 文件与进程

`paths.py` 统一选择 `data/` 或 `demo-data/`。两者的资料、缓存和窗口状态分开；生成样本只写演示目录。原生二进制构建到 `~/.cache/page-between/` 的独立模式目录，不加入 Git。

| 文件                                     | 内容                                 |
| ---------------------------------------- | ------------------------------------ |
| `library.json`                           | 书籍元数据、目录、解析开关、任务状态 |
| `books/<id>/`                            | 导入副本、正文、图片、字体、转换结果 |
| `state.json`                             | 偏好、进度、书签                     |
| `cache/ocr-v3/`                          | 按书 / 页 / 模式缓存的 OCR           |
| `palm-window.json` / `palm-command.json` | 原生窗口状态和复用指令               |

HTTP 只绑定回环地址，检查 Host / Origin；静态读取隐藏文件受限，非活动资料目录与原始状态文件不通过静态路径提供。电子书内容在禁用脚本和外部连接的 iframe 中显示，包内资源需要保持在本书目录范围。

## 本地接口

| 方法与路径                                 | 作用                                 |
| ------------------------------------------ | ------------------------------------ |
| GET `/api/library`、`/api/library-version` | 书籍、任务与变更版本                 |
| GET `/api/formats`                         | 支持格式、默认解析值与原生小窗可用性 |
| POST `/api/import`                         | 原始文件导入与去重                   |
| POST `/api/books/<id>`                     | 书籍设置和页码校正                   |
| POST `/api/books/<id>/chapters`            | 不可变目录版本、旧修订保护、章节调整 |
| GET / POST `/api/state`                    | 共享阅读状态与偏好                   |
| GET `/api/ocr?book=...&page=...`           | 当前扫描页的文字与对象               |
| POST `/api/palm`、GET `/api/palm-status`   | 开启 / 复用原生小窗及状态            |

接口是本地原型协议，尚未作为稳定 SDK。未来是否复用到正式 macOS 应用，应在阅读交互稳定后再决定。

## 2.21 的目录、精确位置与图片

`chapter_edit.py` 读取归一化原文件，以 UTF-16 全局偏移拆并章节。先写不可变正文版本，再切换权威书库元数据；保存失败时旧内容仍可读。`ui/chapters.mjs` 提供目录编辑和正文分章，结构修订拒绝其他窗口的过期操作。解析开关保留手工版本，清理只移除不再引用的旧正文。

EPUB 在装饰前标记原始节点，定位不依赖当前可见节点序号。PDF 对齐保留原字符几何，整公式 / 表格不做局部文字截断；OCR 没有提供字符时补透明对象锚点。选区携带区块顺序和块内偏移，跨列此前范围按阅读顺序判断，未知页内顺序不会纳入当前页。附近文字直接从原文位置构造，并保存每条回答实际使用的快照；Unicode 截断保留完整代理对。

`ui/book-images.mjs` 将当前书籍的图像转为有限尺寸栅格；`book_images.py` 只接受有界 PNG / JPEG 数据或本书已保存附件，解码去除元信息、按内容校验并保存到所属书籍。模型请求在本轮选择附图时才包含 `image_url` 内容块。恢复从暂存书库校验图片，不能依赖恢复前的活动目录。未对应本次来源的引用编号单独提示，模型输出仍通过安全排版。

## 2.13 的界面模块

`ui/library.mjs` 按 ID 缓存书籍卡片，筛选只改变可见性，星标不替换按钮或图片。`ui/feedback.mjs` 管理有语义、可暂停计时和可撤销的通知；撤销动作继续使用原有书籍 / 书签接口。`ui/shared.mjs` 集中图标与 HTML 转义。主脚本仍协调已有阅读状态和服务通信，没有引入第二套状态存储。

常读成为书库筛选；导入处理结果由侧栏底部打开对话框查看。旧 shelf / imports 路由兼容转入新的入口。具体取舍见 [评审沟通记录](REVIEW_DIALOGUE.md)。

## 2.14 的任务恢复与书内 AI

任务按书替换旧记录，并同步书籍当前状态；界面聚合旧数据时以书籍状态为准，避免历史失败成为永久告警。`characterRect` 同时服务分页和滚动锚点，避免内联文本节点边界的空 Range。

AI 入口复用选区和当前阅读位置，`ui/tutor.mjs` 管理问题、记录、回复与出处按钮。`ai_tutor.py` 只从后端读取模型配置，使用兼容 Chat Completions 的 HTTP 请求，按书保存 `ai-conversations.json`；生成前先保存问题，成功或失败后更新同一回复，服务中断的生成记录可以重试。

已保存的来源在追问时保持不变；每次请求使用原文、附近内容和有界的近期对话，不默认上传整本书。Pandoc 排版后清理输出标签与属性，MathML 保留，URL、脚本和外部图片移除。Python 模型请求不跟随重定向，避免将认证与资料转发到其他地址。

## 2.15 的应用内服务设置

`ui/settings.mjs` 管理独立的服务表单，阅读偏好重绘不会销毁这些表单。`GET /api/settings` 只返回非敏感字段与凭据是否存在；保存和测试分别使用 `/api/settings/save`、`/api/settings/test`。模型测试使用草稿快照，实际回答读取同一套服务配置。

`service_settings.py` 负责旧 `.env` 兼容、配置校验、目标地址变更保护与持久化。普通设置放在 Application Support；`native/Secrets.swift` 通过 Security.framework 保存凭据。值仅经过后端与 helper 的管道，进程参数和日志中没有 Key。替换凭据时先创建新条目，再原子替换设置文件，最后清理旧条目；文件保存失败保留原设置与原凭据。

更完整的前后端 App 化问题与交付门槛见 [APP_READINESS.md](APP_READINESS.md)。服务配置完成不等于 MinerU 任务、主窗口或安装包已经完成。

## 2.16 的桌面宿主与数据边界

`native/App.swift` 承担主窗口、菜单、文件面板、后端进程和全局掌上呼出。`Palm.swift` 同时可作为开发原型的独立窗口和 App 内的掌上窗口；原生消息限定主 frame 与预期来源。打包后的服务绑定动态回环端口，通过启动请求头建立 HttpOnly / SameSite 会话，普通网页无法直接读取书库。

`paths.py` 分开磁盘位置与 HTTP 命名空间：开发原型仍读项目内数据，安装版使用 Application Support / Caches，书籍始终通过受控的 `/data/books/` 或 `/demo-data/books/` 地址读取。`book_import.path_for()` 校验资源边界，兼容 macOS 的 `/var` 与 `/private/var` 别名。服务仅提供前端资源和已登记书籍，不开放源码、目录列表或原始状态文件。

JSON 写入使用独立临时文件、flush / fsync 和原子替换。迁移在独立目录复制、逐文件校验并确认源记录未改变后切换，旧目录不删除。App 退出先保存阅读位置，再结束自有服务；父进程意外退出也会触发服务清理。延迟退出从 RunLoop 发起，避免在 GCD 主队列回调中等待自身，造成退出卡住。

窗口同步按每本书的位置时间戳判断，允许稍后应用已观察过的更新；不以整个状态最后写入者代替位置归属。输入与选择时暂缓同步，失焦时先提交本地位置，再在恢复焦点时读取最新位置。

## 2.17 的云解析与任务恢复

`ui/mineru.mjs` 提供页段、整本、复用 / 重识别入口；`POST /api/jobs/mineru` 在现有按书任务中运行，`POST /api/jobs/pause` 停止本机后续工作。任务保留类型、页段与重识别操作 ID，启动恢复不把云任务误当成本机目录任务。TXT 的基础读取即使关闭增强也会恢复。

上传为原 PDF 的页段副本，每批最多 150 页。服务请求携带 Token，签名上传 / 下载地址不附带 Token，也不跟随重定向。断点只保存任务 ID 和输入身份，不保存 Token 或签名 URL。下载与解压有容量、路径和域名限制；合并结果保留之前完成的页。

OCR 缓存保留本机原始结果，在每次读取时叠加最新增强数据，避免云解析后旧缓存遮蔽新结果。对象原图直接裁切已渲染的原 PDF；复制图片在用户操作内建立 ClipboardItem，再异步解码，以适配 WebKit 剪贴板时机。来源保存 PDF 页内比例坐标，缩放后仍可返回对应区域。

匿名生成器附带 `scripts/demo-enhancement.json`，仅含自编样例的实际解析结果；无需配置云服务即可评审对象取用。

### 2.30 的英文 OCR 选择层

`ui/ocr-layer.mjs` 将识别数据与透明选区渲染分开。Tesseract 英文字符沿用原始横向位置，以行 bbox 统一垂直命中带，词间空格单独定位；相邻字符的边界取墨迹间中点并限制在字符中心之间。同行采用 inline-block 文本单元，避免独立绝对定位字符使反向原生拖选的初始锚点跳动。中文 Vision 与原生 PDF.js 继续原有布局，不改缓存结构，也不重新发起识别。

答疑按实际 DOM 空白重建英文附近文字；有校正映射与无映射片段混选时，无映射片段也从 DOM Range 读取，避免人为在每个字母之间插入空格。缺字与错误坐标仍保守处理，公式和表格整体取用逻辑保持独立。

### 2.29 的连续准备与已导入文档处理

PDF 书库卡片、阅读顶栏与任务面板都进入「文档处理」。本地划词准备与 MinerU 内容增强分别统计覆盖率，不能用其中一个 ready 推断另一个完成。`pdf_preparation.py` 以独立队列处理当前页、附近预取和整本任务；当前页请求优先，阅读位置更新后替换旧的预取计划，默认预备后 3 页与前 1 页。整本本地任务支持暂停、继续和重启恢复，不占用云任务槽。

字符几何按原文件 SHA-256、语言和识别版本存入书籍目录的 `selection-text-v1/`，有效旧字符缓存迁入同一位置。临时缓存清理保留这些结果，书库备份包含它们。检索索引直接读取同一份已保存文字，准备页变化会使索引失效重建；检索不会自行发起 OCR。原生文字层和 MinerU 结构仍按原来的优先级使用。

MinerU 固定本次请求页段与待处理计划，每批最多 150 页、上传字节不超过 200,000,000，过大继续拆小，单页仍超限则明确报错。返回结果必须与所提交页数对应，拒绝缺页、重复索引和越界索引。每批成功即原子更新原页结构并通知阅读器，当前画布与阅读位置保留；后续批次失败不撤销已发布结果。续接使用原计划和远程任务身份，覆盖率增加不会另建重复任务；无效输出需要显式重试，启动时不自动重新提交。

## 2.18 的内容对齐、全文索引与逐段答疑

`pdf_selection.py` 在区块内对齐标准化字符并保存 UTF-16 范围；`ui/pdf-selection.mjs` 将 DOM Range 映射回解析文字，保留原生 PDF / OCR 的字形几何。数学片段整体展开，低相似区块和无法确认的字符回退。对齐请求带文字层版本，OCR 准备有进行中标记，避免重复异步响应附着到已经替换的节点。

`book_index.py` 在 Caches 保存每本书的 SQLite FTS5 索引，按源身份、结构、增强修订与 OCR 缓存变更重建。中文使用单字 / 相邻双字，英文使用词项；编号定义单独索引。位置包含章 / 段落 / 字符或 PDF 页 / 比例坐标。扫描 PDF 优先增强文字，再原生文字、已完成 OCR；不会自动识别尚未阅读的全部扫描页。

`POST /api/index/search` 返回完整来源快照与覆盖状态；前端候选先预览再跳转，歧义不自动定向。AI 检索默认按原始提问位置过滤后文，每条回答保存至多六段来源与编号。引用来自已保存快照，不依赖未来可能改变的索引行号。

`POST /api/ai/start` 先持久化问题，再后台请求 SSE，间隔保存部分文字；面板读取同一会话逐段显示。`POST /api/ai/cancel` 设置取消并关闭已建立的模型连接，部分回答保留为已停止，支持重试。原同步接口保留用于验证。中断与缺少完成信号的流不会伪装成成功回答。

## 2.19 的 EPUB 导出和恢复事务

`epub_export.py` 沿用原生 EPUB / 转换后的包，TXT 与结构化 PDF 使用随包 Pandoc 输出 EPUB 3。区块锚点、唯一编号引用、MathML、表格与原 PDF 裁图进入同一文档；实际输出检查发现未渲染数学片段时，以对应原块图片重建。`META-INF/page-between.json` 只记录源身份和页序，导入器恢复原 PDF 关联。

`library_data.py` 把原书、规范化解析结果和阅读 / 对话快照写入带 SHA-256 清单的备份。已完成的云中间缓存、OCR / 搜索缓存、服务设置和钥匙串不进备份。恢复验证容量、路径、哈希和本地资源，并重新安全排版对话 HTML；先写独立暂存目录，未确认时不启用。

确认后，下一次服务启动先取得书库目录外的实例锁，再验证暂存文件、移动原库到保留目录并启用新库。中间重启可从已有目录状态继续，替换失败则回退。原生宿主管理重启，关闭其服务进程组；未完成解析恢复为可继续状态，不因恢复而自动重新上传。

`/api/data/*` 提供信息、备份、校验恢复、确认 / 取消、回到恢复前与缓存清理。原始导入和备份上传按块写入磁盘，短传输不会登记书籍。`/api/downloads/<id>` 只提供受认证的导出文件；安装版通过 AppKit 保存面板与临时文件替换保存，普通浏览器使用下载。
