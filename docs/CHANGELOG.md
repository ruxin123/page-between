## 安装与升级

所有安装包均为 Apple Silicon（arm64）开发预览版，使用 ad-hoc 签名，尚未经过 Apple 公证。解压后将 App 放入应用程序文件夹即可运行，运行组件已随包提供。

普通版使用个人书库；演示模式仅供内部截图与开发验证，不对外提供安装包。退出 App 后用新版替换旧版，阅读数据与服务配置继续保留。若需要回退，建议先在当前版本备份书库；旧版读取新版数据的兼容性没有保证。

当前归档从 0.5.7 开始，更早的开发过程见提交历史，未提供相应安装包。后续版本继续在本文件及对应 Release 中记录功能变化。
