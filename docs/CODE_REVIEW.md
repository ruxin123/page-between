# 代码评审指南

## 运行与验证

按 [README](../README.md) 配置环境并启动匿名演示。运行 Node 与 Python 测试；无需私人书库、已有缓存或云端 OCR 凭据；AI 回归使用本机模拟 HTTP 服务，实际模型可在「设置 → AI 答疑」中配置，开发环境也兼容本机 `.env`。

## 建议阅读顺序

先查看 [评审沟通记录](REVIEW_DIALOGUE.md)，其中说明了上一轮源码判断与本轮改动。

1. `paths.py`、`server.py`：模式隔离、文件与状态、任务、HTTP 边界和原生组件启动。
2. `book_import.py`、`parse_text.mjs`、`core.mjs`：格式适配、EPUB 资源、章节规则与位置。
3. `pdf_enhancement.py`、`native/OCR.swift`：OCR 坐标、目录判断、页码映射及缓存。
4. `page-layout.mjs`：分页尺寸、动画取消、真实文字的几何位置、资源释放。
5. `ui/library.mjs`、`ui/feedback.mjs`、`ui/shared.mjs`：卡片复用、通知撤销、键盘焦点与输出转义；以及 `app-v2.mjs`：异步加载、模式切换、字符锚点、书签、文字选择与主 / 小窗同步。
6. `native/Palm.swift`：窗口层级、尺寸、快捷键、桥接与关闭保存。
7. `ai_tutor.py`、`ui/tutor.mjs`：来源、对话隔离、模型请求、失败重试与安全 Markdown / MathML。
8. `service_settings.py`、`native/Secrets.swift`、`ui/settings.mjs`：非敏感配置、钥匙串、草稿测试与凭据保留 / 替换 / 移除。完整交付边界见 `APP_READINESS.md`。
8. `tests/` 与 `scripts/create_demo.py`：回归范围、生成样本和缺口。

文件名保留 `app-v2.mjs` 以对应当前原型，旧版入口和样本专用脚本不属于公开运行链路。

## 请重点检查

| 领域         | 评审问题                                                                |
| ------------ | ----------------------------------------------------------------------- |
| 导入边界     | ZIP 路径、XML 实体、本地资源、文件大小、转换超时、重复导入是否正确处理  |
| 服务边界     | Host / Origin、静态文件范围、个人与演示资料隔离、错误信息和本地部署假设 |
| 并发与持久化 | JSON 原子写入、任务与开关竞争、多窗口进度、书签修改及关闭窗口时的状态   |
| 异步渲染     | 新请求覆盖旧请求、字体 / 图片迟到、PDF 取消、章节衔接与错误恢复         |
| 位置与选区   | 长段落跨页、重排后的字符锚点、弹窗遮挡、选择原生文字或 OCR 时的差异     |
| 性能与释放   | 长 TXT、长 EPUB、PDF 画布、OCR 队列、动画克隆与事件监听生命周期         |
| 原生桥接     | JS 消息来源、URL 与 IPC 指令、重复开启窗口、快捷键注册、离焦行为        |
| 可维护性     | 是否有能合并或删除的逻辑；只提出与当前目标相关的必要抽象                |

本仓库是面向本机的原型，请审查其实际假设；不能直接推断它适合公网、多租户或正式教学使用。
