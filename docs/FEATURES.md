# 产品范围与功能说明

## 产品目标

在同一个个人阅读空间中兼顾小说与严肃学习。成熟电子书格式沿用原有结构；扫描教材保留原书版面，补充导航与可取用文字。学习辅助提供术语、翻译、编号引用跳转、本书此前资料检索和带出处的 AI 对话。

首要平台为 macOS，主要用户是个人读者。当前桌面版本为 0.5.14；适用平台、历史交付与本轮验证证据见 [交付清单](APP_READINESS.md)。

## 界面职责

| 页面           | 主要任务                                 | 进入 / 离开                          |
| -------------- | ---------------------------------------- | ------------------------------------ |
| 书库           | 找书、导入、继续阅读、常读筛选和搜索     | 点击封面进入阅读                     |
| 导入与处理面板 | 查看后台进度、错误与完成结果             | 侧栏底部打开，选择书籍直接进入阅读   |
| 设置           | 阅读排版、模型、MinerU 与本机数据管理   | 保存后供后续阅读与请求使用           |
| 阅读页         | 给正文主要空间                           | 目录 / 设置 / 提问按需出现，返回书库 |
| 掌上窗口       | 在屏幕角落阅读文字书                     | 主阅读器打开，独立置顶 / 关闭        |

常读是书库内的筛选，旧书架地址仍可使用。常读切换和删除书签可通过通知撤销；任务入口在空闲时也保留，便于找回错误与处理记录。

书库与阅读分开，避免所有模块常驻挤压正文。主窗口进入阅读时默认展开章节目录，可手动收起；掌上小窗默认收起。带出处的 AI 对话位于独立浮层。

## 导入与增强

导入时逐本选择分类与文档解析开关。PDF / TXT 默认开启；EPUB 等默认关闭。解析失败时保留原件和可读部分，通过处理状态说明结果。

EPUB 的目录、阅读顺序、图片与本地链接直接使用原书包。TXT 通过共同规则识别章、回、卷和英文标题。PDF 先使用自带书签和文字层，缺失时再 OCR；印刷目录与 PDF 文件页序需要单独校准。

当前没有为每本文件单独编写目录代码，也没有将 MinerU 作为所有格式的入口。PDF 可按选定页段或整本提交 MinerU 云解析，在后台暂停、继续与恢复；未主动提交时不调用云服务。

支持 PDF、EPUB、TXT、CBZ、MOBI、AZW、AZW3、MD、Markdown、HTML、HTM、FB2、DOCX、ODT、RTF。转换格式采用单文件导入：图片须内嵌或包含在文件包中，缺少外部图片会报告错误并保留原件。云解析上传后重启继续查询原远程任务；「重新提交解析」才会明确创建新任务。

PDF 原有书签保留页码及页内落点，同页多个章节可分别定位，旧书库自动补全原目录位置。

PDF 卡片和阅读顶栏的「文档处理」分别展示本地划词与 MinerU 覆盖率。本地可提前准备整本、暂停和继续；阅读时优先处理当前页，提前准备后 3 页和前 1 页。字符结果随书保存并纳入备份，清理临时缓存前会迁移可用的旧结果。MinerU 可补全未解析页或选择范围，每批完成即生效；批次检查不重不漏，结果异常保留其他成功页，重试继续处理缺失部分。

## 阅读方式

2.34 保留数学样式与文字间距，支持带空格列格式的分段公式，去除重复编号与错误列表；旧回答可按新规则重新显示，复制仍为原文。

2.33 修正原生文字 PDF 的字体缩放与行高亮：按原书字形定位，同行小型大写字母合并显示，行间与分栏留白。大型 PDF 逐页应用护眼效果并释放离屏缓存；画布异常可恢复，绘制失败提供单页重试。复制仍使用原始文字与既有校正流程。

2.22 修复 WebKit 点击 EPUB 正文后的划词和键盘翻页。取消选区即收起操作条；答疑框可拖动标题，聚焦标题后可用方向键微调。扫描 PDF 使用 OCR 字符坐标定位，公式和图表仍完整取用。

2.31 修复跨行拖选经过空白时反选到页首；扫描件高亮合并为每行连续色带，去掉逐字符条纹和页边高亮。提问选段直接显示渲染的文字、公式与表格，原图仍可查看；复制保留原始内容，本机预览无需配置模型。

2.30 改善英文扫描件的原生精细拖选：同行字母和标点使用统一选区高度，单词空格独立定位，正反向选取采用同一行文本布局；复制与提问保留单词边界。已有 OCR 结果直接复用；原始坐标识别错误仍可能影响精度。

文字书和掌上窗口默认分页；PDF 默认连续滚动。用户可选择其他模式，主窗口文字模式、PDF 模式和掌上模式分别记忆。

分页通过真实 DOM 多栏完成，文字仍然可选，图片和链接仍可访问。换页以轻缓位移、淡入淡出和低强度阴影表达，不使用大幅透视旋转。动画尊重系统减少动态效果的偏好。

目录始终指向章节 / 原 PDF 页，屏幕分页则会随字体与窗口变化。文字锚点用于恢复内容位置；不能把当前屏幕页数当作永久位置。

0.5.13 根据实际可见范围准备 PDF 页面，使用真实页面比例保持混合尺寸跳转；书签支持跨窗口位置去重，导入失败可只重试失败文件，保存书籍设置和检索跳转绑定来源书。

## 内容取用与书内答疑

1. 正文直接拖选，选区旁出现复制与提问；顶栏也可打开本书记录或围绕当前页提问。
2. 配置本机模型后可发送真实请求，选段与附近文字作为参考；模型用 [1] / [2] 标注已提供的资料，不得捏造未提供的书内页码和定理。
3. 支持连续追问、失败重新生成，原文与对话保存在本机。点击出处回到书中，返回按钮保留跳转前的位置。
4. 生成过程中可继续阅读；关闭面板或刷新后仍能在本书记录找回。复制原文与对话不会调用模型。
5. EPUB 图片、表格、MathML 支持完整对象取用；PDF 的 MinerU 结果提供完整公式 LaTeX、表格制表符文字及原图。确认模型支持图像后，可按问题附带原图，也可只发送文字；精度仍取决于识别与模型结果。

定理 / 定义 / 公式编号支持候选预览、跳转与返回；AI 按需检索本书当前位置之前的资料，保存原文和位置快照。检索基于词项与原文位置，扫描书显示实际已解析范围，具体行为见下方学习辅助说明。

## 掌上阅读

使用系统标题栏移动窗口，窗口位置随系统保存并在重新打开时恢复。

使用真实的 macOS NSPanel，内部复用同一个阅读页面。默认置顶，允许取消；改变窗口大小时调整字号，维持接近的信息密度。位置、书签和字体主题与主窗口共享；浏览方式可独立选择。

聚焦小窗时使用 ← / → 或空格；其他 App 聚焦时使用 Control + Option + Command + 左 / 右方向键。用户已在 0.5.7 确认后台双向翻页正常，运行状态同时记录到实际的离焦快捷键与无错误的 WebKit 执行。

该模式主要服务于可重排文字书，暂不以扫描教材和漫画为重点。浏览器也可通过 `/?mode=palm&book=demo-a` 检查小窗页面布局，但浏览器页面本身不具有 macOS 系统置顶能力。

## 评审边界

后续评审重点：模块划分是否清楚、阅读是否安静、翻页是否自然、位置是否稳定、导入与增强状态是否易懂、选择与提问是否打断阅读、小窗是否方便。

当前暂缓：商业账号体系、云同步、完整 AI 教学、跨书知识库、复习系统、手机原生端。提出这些建议时请标为后续方向，避免挤占本轮阅读体验评审。

## 2.21 的位置与图表补充

TXT 可在目录中改名、合并、恢复上一版和重新识别，在正文划选后从当前位置分章。原文件保持不变，目录版本切换后按原文字符恢复书签与对话出处。

PDF 跨区选取保留完整公式和表格，包括 OCR 漏掉全部表中文字的情况；已解析的透明对象仍可参与选区。图像答疑会保存选段原图，刷新、备份与恢复后可回看并返回原书。模型能力与每次附图分别控制。

附近文字按实际位置截取，重复选段不会回到首次字符串匹配；回答可展开本次发送的文字。此前资料按章节 / 字符 / 原始节点或 PDF 区块顺序过滤，未知页内顺序时只纳入更早页。不存在资料对应的引用编号会提示核对。

## 2.18 的学习辅助

- 放大镜 / ⌘F 打开书内检索，按术语、原文或定理编号查询，支持只看当前位置之前。编号重复时保留全部候选。文字书中编号引用可直接点击，PDF 可选择后查书内。
- 结果和 AI 来源可先预览，再前往原文，返回按钮保留跳转前的位置。来源快照随每条回答保存，刷新后可回顾。
- AI 请求按需检索至多六段此前资料，逐段返回，支持停止和失败重试。扫描书显示已解析范围，不会把缺失页当成已检索。
- 原生 PDF 与扫描 OCR 保留原始文字层几何；复制与提问按区块字符映射取解析文字。中文、英文、连字、emoji 边界与跨段已验证，低可信对应关系回退原文字。

## 2.19 的导出与数据管理

书籍设置提供 EPUB 导出：优质格式保留原包，TXT 按章节生成，PDF 以已解析的块生成带原页锚点的重排内容。公式转换为 MathML，表格保留单元格，插图取自原 PDF。无法转换的复杂公式保留完整原图；未识别扫描页也保留原页。重新导入后，原 PDF 在书库时可直接查看对应原页并返回。

书库与数据设置提供备份、校验、取消、确认恢复、恢复前书库回退与缓存清理。备份恢复只更换图书和阅读记录，不搬运或覆盖服务凭据。后台未完成的云任务保留断点；清理只移除可重新生成的内容。当前备份容量为压缩 2 GB、展开 10 GB。
