# 产品范围与功能说明

## 产品目标

在同一个个人阅读空间中兼顾小说与严肃学习。成熟电子书格式尽量沿用原有结构；扫描教材保留原书版面，再补充导航与可取用文字。先验证阅读舒适性和内容取用，之后再建设更深入的数学辅导。

首要平台为 macOS，主要用户是个人读者。当前是可运行的交互原型，不是完整商业产品。

## 界面职责

| 页面         | 主要任务                                 | 进入 / 离开                          |
| ------------ | ---------------------------------------- | ------------------------------------ |
| 书库         | 找书、导入、继续阅读、分类和搜索         | 点击封面进入阅读                     |
| 书架         | 保留星标常读书籍                         | 与书库共享同一本书的状态             |
| 导入管理     | 查看导入与增强处理结果                   | 选择书籍直接进入阅读                 |
| 全局阅读设置 | 调字体、主题、各类浏览模式，查看排版预览 | 返回书库后保留偏好                   |
| 阅读页       | 给正文主要空间                           | 目录 / 设置 / 提问按需出现，返回书库 |
| 掌上窗口     | 在屏幕角落阅读文字书                     | 主阅读器打开，独立置顶 / 关闭        |

书库与阅读分开，避免所有模块常驻挤压正文。目录是临时导航面板，较长的提问草稿位于独立浮层。

## 导入与增强

导入时逐本选择分类与文档解析开关。PDF / TXT 默认开启；EPUB 等默认关闭。解析失败时保留原件和可读部分，通过处理状态说明结果。

EPUB 的目录、阅读顺序、图片与本地链接直接使用原书包。TXT 通过共同规则识别章、回、卷和英文标题。PDF 先使用自带书签和文字层，缺失时再 OCR；印刷目录与 PDF 文件页序需要单独校准。

当前没有为每本文件单独编写目录代码，也没有将 MinerU 作为所有格式的入口。MinerU 整书服务仍属后续增强方向。

## 阅读方式

文字书和掌上窗口默认分页；PDF 默认连续滚动。用户可选择其他模式，主窗口文字模式、PDF 模式和掌上模式分别记忆。

分页通过真实 DOM 多栏完成，文字仍然可选，图片和链接仍可访问。换页以轻缓位移、淡入淡出和低强度阴影表达，不使用大幅透视旋转。动画尊重系统减少动态效果的偏好。

目录始终指向章节 / 原 PDF 页，屏幕分页则会随字体与窗口变化。文字锚点用于恢复内容位置；不能把当前屏幕页数当作永久位置。

## 内容取用与提问

1. 正文直接拖选，选区旁出现复制与提问。
2. 提问草稿包含书籍与原文位置，用户补充自己的问题。
3. 可复制选中文字、来源与问题；该动作不会自动发送网络 AI 请求。
4. EPUB 图片、表格、MathML 支持完整对象取用。扫描 PDF 的完整公式对象依赖外部增强结果，不能把普通 OCR 当作精确公式解析。

后续数学学习目标包括定理 / 定义引用跳转与返回、优先使用本书此前知识解释问题、按原文位置回顾对话。当前不以虚构 AI 回答模拟这些能力。

## 掌上阅读

使用真实的 macOS NSPanel，内部复用同一个阅读页面。默认置顶，允许取消；改变窗口大小时调整字号，维持接近的信息密度。位置、书签和字体主题与主窗口共享；浏览方式可独立选择。

该模式主要服务于可重排文字书，暂不以扫描教材和漫画为重点。浏览器也可通过 `/?mode=palm&book=demo-a` 检查小窗页面布局，但浏览器页面本身不具有 macOS 系统置顶能力。

## 评审边界

当前优先验收：模块划分是否清楚、阅读是否安静、翻页是否自然、位置是否稳定、导入与增强状态是否易懂、选择与提问是否打断阅读、小窗是否方便。

当前暂缓：商业账号体系、云同步、完整 AI 教学、跨书知识库、复习系统、手机原生端。提出这些建议时请标为后续方向，避免挤占本轮阅读体验评审。
