## 本轮修复

- PDF 连续阅读原先只准备当前页与前后页，短页同屏更多时会留下未绘制页；改为根据真实可见范围调度，离屏图像继续释放。
- 单一高度占位使混合尺寸书籍跳页后漂移；首次读取轻量页面几何并缓存比例，短末页也预留足够滚动空间。
- 书签单窗保存锁与服务器位置去重协同，避免连点或两窗并发产生重复；失败解锁，仍支持移除与撤销。
- 导入固定批次，忙时拒绝追加和重复提交，关闭重开保留进行中批次；失败后只重试失败文件。
- 书籍设置保存绑定来源书，等待中切换书籍不会改写新书；关闭对话框后失败也显示提醒。
- 新书检索开始时清空旧结果，跳转前再次核对书籍与请求代际。

## 安装包验收

0.5.13 / 237 普通版与演示版的新构建分别通过独立冻结服务验收，包括本机 OCR、持久化、备份恢复、章节编辑、图像请求、重启及 EPUBCheck；普通版另外通过 16 个格式样本。两包 21 份核心前端资源与源码逐字节一致，冻结后端再次核对书签 19 / 20 字符边界。

原生 WKWebView 程序检查通过：TXT / EPUB / PDF 默认目录、跳章保存与返回、原生高亮、模拟画布丢失后保留选区，以及 MathML 结构。该程序检查不是实体鼠标或后台系统按键验收。

两版均已安装并重新打开，原书、阅读记录、对话、附件和服务配置在升级前后校验一致，钥匙串辅助组件字节不变；旧 App 已保留。发布归档另核对 ZIP 完整性、解压后的严格签名与摘要。

模拟 `contextlost` 证明恢复分支有效，不能代表稳定复现系统 GPU 回收。上述结果是给定样本与流程的证据，不是“任意书籍、网络与系统组合都无问题”的承诺。
