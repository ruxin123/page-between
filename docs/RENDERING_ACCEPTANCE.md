# 划词、识别与渲染专项验收

目标：检查原文到识别坐标、划词、复制和提问预览的完整链路，复现并修复可控的内容和显示错误。真实书籍只在隔离副本中测试；公开样本使用原创内容。以下状态随实际证据更新，历史版本的通过不能直接用于本轮结论。

## 本轮执行记录

- 两种浏览器分别执行 14 组端到端脚本，包含绘制、选区、预览、公式布局、章节、目录、分页和故障注入；28 组通过。`verify_scan_selection.cjs` 另使用实际 OCR 和独立原始像素 / 字体坐标测量目标，不用同一 OCR 框反推预期。
- 隔离复杂书库的六本书在两种浏览器中完成目录跳转、持久化、两个窗口同步及重开；两本教材各选 13 个代表页合计 26 次预览流程，不把这些页称为逐页人工校对整本。
- 原生隐藏窗口的复现保持帧回调为零；修复后仍得到非空 PDF 像素。最终冻结普通版在不依赖开发环境 PATH 的情况下完成 OCR、缓存保存 / 重启 / 备份恢复、EPUB 导出与 EPUBCheck。
- 详细机器日志与真实书籍截图仅保存在本机 `qa/rendering-audit/`；公开脚本、根因和结果摘要可用于下一轮复核。原始真实书籍与服务凭据没有进入发布物。

复跑前使用隔离书库启动本地服务，避免测试脚本调整个人阅读状态。OCR 几何检查先运行 `python scripts/verify_ocr_geometry.py`，再运行 `node scripts/verify_scan_selection.cjs READER_URL webkit`（或 `chromium`）；跨页检查先在同一隔离库运行 `scripts/create_rendering_sample.py`。其余浏览器脚本接受 `READER_URL webkit|chromium`，格式详见文件开头。
