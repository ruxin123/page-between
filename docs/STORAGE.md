# 存储与清理

| 内容 | 保留策略 |
| --- | --- |
| 原书、目录、阅读进度、书签、答疑记录 | 书库数据，清缓存不会删除 |
| OCR 划词结果、MinerU 结构结果 | 随书长期保存，避免重复识别与云端调用 |
| 划词翻译 | 默认只在当前会话中显示，不自动写盘或跨次复用；主动收藏才保存 |
| 全文检索索引 | 按需生成并复用，可手动清除后重建 |
| EPUB / 备份临时导出 | macOS 保存成功后删除；其他临时导出保留不超过一小时，限制待取用数量 |
| MinerU 原始 ZIP、解压布局与拆页 PDF | 成功写入阅读结果后删除，未完成任务保留续传资料 |
| PDF 页面位图 | 仅在内存中按既有预算保留，不为每页永久存图 |
| 书源网页资源 | 关闭窗口时清理资源缓存，登录会话单独保留，可手动清除登录 |
| 构建中间目录 | 构建验证成功后删除，只保留最终 App |

设置「书库与数据」显示索引、导出、旧版 OCR 副本与云解析中间文件的占用。清理旧 OCR 副本前会先迁移有效划词结果，清理缓存不会让整本已准备的内容丢失。

历史安装包由 GitHub Releases 提供；本地保留最新包即可。开发验收的书库副本、截图和构建日志不是用户书库，验收完成后可清理。手动导出的备份和原始测试语料不作为普通缓存自动删除。
