# Mac 与 iPhone 迁移

Mac：设置 → 书库与数据 → 设备迁移。iPhone：书库 → 更多 → 设备迁移。

1. 选择“导出迁移包”。iPhone 接着用“发送或存储迁移包”。
2. 通过隔空投送、iCloud Drive 或数据线传输 `.pbtransfer` 文件。
3. 接收设备选择“导入迁移包”；iPhone 也可从“文件”打开迁移包。

迁移包含 PDF、EPUB、TXT、FB2、CBZ 原件、阅读进度、书签、页边笔记、翻译收藏、答疑及引用、保存的原图和单书排版。两端均可导入旧迁移包；旧版 App 需要更新后才能读取新版包。Mac 会列出跳过的其他格式。

已有同书按原件 SHA-256 识别。导入补齐缺少的记录；同一条记录、当前进度和已有单书排版保留接收设备的版本。最近删除中的书不会被自动恢复。迁移是一次文件交换，不会同步后续修改或删除。

PDF 按原页和页内坐标恢复。EPUB 优先匹配原书正文资源，TXT 优先按原文字符位置对应章节；两端字体和分页不同，显示位置可能略有偏移。接收设备会使用支持的字体和主题，桌面特有的设置可随迁移包带回。

单书原件上限 200 MB，全部资料解包后合计 1 GB，阅读记录合计 64 MB，清单 4 MB。导入前核对路径、体积、CRC 和文件 SHA-256；损坏或缺少附件的包会拒绝。可恢复的个别书籍错误会在结果中列出。

迁移不包含服务账号、API Key、文件夹分类和 OCR／MinerU 解析结果。设备完整恢复使用各自的备份格式：Mac `.pbbackup`，iPhone `.pbmobilebackup`。迁移包含书籍原文和私人笔记，请通过可信渠道传输。
