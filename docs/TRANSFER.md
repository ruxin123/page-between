# Mac 与 iPhone 迁移

Mac：设置 → 数据 → 设备迁移。iPhone：书库 → 更多 → 设备迁移。

1. 选择“导出迁移包”。iPhone 接着用“发送或存储迁移包”。
2. 通过隔空投送、iCloud Drive 或数据线传输 `.pbtransfer` 文件。
3. 接收设备选择“导入迁移包”；iPhone 也可从“文件”打开迁移包。

包含 PDF、EPUB、TXT、FB2、CBZ 原件、当前进度和书签。Mac 其他格式在导出结果中列为跳过；单书上限 200 MB、合计 1 GB、清单 4 MB。超限会提示失败，原书不变。

同书按原件 SHA-256 去重。接收设备已有的书，包括最近删除中的同书，保留本机记录；不会覆盖进度，也不会自动恢复已删除的同书。PDF 保存原页和纵向位置；文本按正文顺序、章节内进度恢复，分页、目录结构或文本分章不同可能产生偏移。不是逐字锚点同步。

包中不含账号、模型密钥、设备设置、文件夹分类、AI 对话、翻译收藏和 OCR／MinerU 解析结果。这些数据仍保存在原设备；Mac 的完整 `.pbbackup` 备份继续用于完整恢复。迁移前如需保留所有桌面资料，请另存完整备份。

所有包先核对清单、体积、路径、CRC 与原件 SHA-256，再写入书库。损坏包和清单外文件会拒绝；有效包中个别书籍格式损坏则报告具体失败，成功导入的书籍保留，再次导入可跳过已完成的同书。不会删除接收设备的其他书籍。

迁移文件包含图书原文，请只通过你信任的渠道传输。导出暂存沿用限时清理；手机在关闭迁移窗口时清除暂存，迁移后原件属于书库资料。
